# MyPortfolio

A personal portfolio website showcasing my journey as a B.Sc IT student, my technical skills, and the projects I have built.  
This site is designed to be simple, responsive, and professional — making it easy for recruiters, collaborators, and peers to learn more about me.

## 🚀 Features
- Responsive design with modern layout
- Sections for About Me, Skills, Projects, Education, and Contact
- Dark/Light mode toggle for better user experience
- Links to GitHub projects and repositories

## 🛠️ Built With
- HTML5
- CSS3
- JavaScript
- Git & GitHub

## 📂 Projects Highlighted
- 🧪 **ChemLab Analytics** – Flask web app for Chemistry & Math data analysis  
- 🌤️ **Weather Prediction** – API‑based weather dashboard  
- 📑 **PDF Merger** – Python utility for managing PDF files
